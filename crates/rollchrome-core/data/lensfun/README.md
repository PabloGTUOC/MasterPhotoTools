# lensfun lens database

The XML files here are the lens database of the lensfun project
(<https://github.com/lensfun/lensfun>, `data/db/`), copied unchanged at lensfun commit `52cf1a7`
(2026-11-04). They are licensed under the **Creative Commons Attribution-ShareAlike 3.0** licence
(CC BY-SA 3.0), a copy of which is in `COPYING.CC_BY-SA_3.0`. The copyright belongs to the lensfun
contributors who measured each lens.

Rollchrome reads them for Develop's lens correction (`docs/briefs/DV-9.md`). They are shipped rather
than downloaded so the application works offline. To update: copy `data/db/*.xml` from a newer lensfun
checkout over these files and record the commit here.
